# Fih Hunter

Fih Hunter is a first person game focused on combat with swords and various guns as abilities made in Unity 3D.

In this game you go through levels and try to rescue the stolen Fih and win the level. You can also collect coins throughout the levels and use them as currency in the in-game hub before a level starts to buy yourself powerups and cosmetics. When completing levels you earn XP and small amount of coins.


## Installation

Downloading and installing the game is very simple, simply click on [this link](https://github.com/FatFih/FihHunter/releases) and select the .zip file from the newest Release.
